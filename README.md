# VACID · Acid Line

A browser acid-bass groovebox for psytrance: a classic analog-style acid synth voice with a 16-step sequencer (accent, slide, octave up/down), plus an automatic rolling sub-bass and kick with sidechain ducking.

**Play it:** https://viktorkmillerfilm-design.github.io/vacid-acid-groovebox/

- Single offline HTML file (`index.html`), vanilla JS + Web Audio, no external assets.
- Works on desktop and iPhone (use landscape; "Add to Home Screen" supported).
- RUN/STOP or Space to play. Click a step LED to select it, then press a key to set its note (press the same key again for a rest).
- RANDOMIZE generates a psy acid line, MODIFY mutates it; long-press (touch), Shift-click or Ctrl+Z to undo.
- EXPORT MIDI: 4 bars, format 1, tracks "Acid" (ch 1) and "Sub" (ch 2); slides are overlapping notes, so enable glide/legato on your synth in Ableton Live.
- 8 pattern slots auto-saved in the browser (localStorage).

Original panel artwork drawn in CSS/SVG; not affiliated with any hardware manufacturer.
